# VK Reforged

VK Reforged — это современный, многофункциональный клиент VK для Android, созданный с использованием Jetpack Compose (Material You).

## Технологический стек

- **UI:** Jetpack Compose, Material 3
- **Сеть:** Retrofit, OkHttp
- **Внедрение зависимостей (DI):** Hilt
- **Локальное хранение данных:** Room, DataStore
- **Мультимедиа:** Media3 (ExoPlayer)
- **Фоновые задачи:** WorkManager, Foreground Services
- **Мониторинг:** Firebase Crashlytics

## Начало разработки

1. Клонируйте репозиторий.
2. Зарегистрируйтесь в Google Firebase (https://firebase.google.com/)
2. Добавьте файл `google-services.json` в директорию `app/`.
3. Откройте проект в Android Studio и выполните сборку.
